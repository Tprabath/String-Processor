A versatile, lightweight library for processing templates or strings by replacing placeholders with dynamic data values. This library provides a flexible and type-safe way to inject data into template/strings across multiple programming languages.


## Overview

The String Processor library offers consistent functionality across different programming languages, allowing developers to work with template processing in their language of choice. Each language implementation provides the same core features while following language-specific conventions and best practices.


## Supported Languages

This multi-language library includes implementations for the following languages:

- **[TypeScript](./TypeScript)** - Full TypeScript implementation with complete type safety and generics support

Additional language versions coming soon!

## Core Features

Across all language implementations, This String Processor provides:

- **Type-Safe Processing**: Full type support with generics for placeholder and value types
- **Flexible Placeholder Formats**: Support for custom placeholder wrapper formats
- **Chainable API**: Fluent interface for easy method chaining
- **Efficient Pattern Matching**: Regex-based replacement for reliable template processing
- **Data Management**: Built-in data structures for managing placeholder-value pairs

## Getting Started

### By Language

Each language folder contains a complete, ready-to-use implementation. Navigate to your preferred language to get started.
